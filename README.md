# Application Django - Coach personnel

## Description
Application de prise de rendez-vous en ligne pour un coach.

## Fonctionnalités
- Authentification client/coach
- Prise de rendez-vous avec contraintes
- Tableau de bord personnalisé
- Historique des séances

## Installation
```bash
git clone <url-du-repo>
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
